# WME to PartnerHub Link
Działa w oknie udostępniania lokalizacji.
*Works in the location sharing window.*
## Funkcje / *Features*
- obok 'Permalink' dodaje ⟳ która odświeża stronę z bieżącym widokiem
  - *adds ⟳ next to 'Permalink' to refresh the page with the current view*

- na dole ramki dodaje dodtkowe pole z linkiem do PartnerHub z możliwością skopiowania lub otwarcia w nowym oknie
  - *adds an additional field at the bottom of the frame with a PartnerHub link that can be copied or opened in a new window*
